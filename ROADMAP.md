# Roadmap

The path from a knowledge base to an Autonomous Content Company, in three
phases. Each phase builds on the one before it.

## Phase 1 — Knowledge Foundation

Establish a single source of truth for the project: vision, architecture,
decisions, and research. Capture how the system should think before writing
any of it in code. This repository is the deliverable of this phase.

## Phase 2 — Architecture

Turn the knowledge into a concrete, cloud-first design: define the core
workflows, the model router, the agent roles, and the runtime that executes
them. Decisions are recorded as ADRs and refined here.

## Phase 3 — Autonomous Creator

Operate the system as an always-on autonomous creator that takes an idea and
produces distribution-ready content end to end, with humans supervising
rather than executing.
