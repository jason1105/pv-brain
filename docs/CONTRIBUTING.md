# Contributing

## Principles
- Documentation first.
- One topic per document.
- Prefer refining existing knowledge over duplication.
- Record long-term architectural decisions as ADRs.

## Knowledge lifecycle
1. Brainstorm
2. Research
3. Knowledge
4. Workflow
5. Agents / Prompts

## Pull Requests
- Keep PRs focused.
- Explain why the change is needed.
- Link related issues when applicable.
