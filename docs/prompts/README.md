# Prompts

Reusable prompt building blocks.

Prompts are the concrete instructions that drive models within a workflow
step. This directory collects reusable, versioned prompt fragments and
templates so they can be shared across workflows and refined over time. Keep
each prompt focused and documented with its intended use.

## Libraries

- [`youtube/`](youtube/) — templates for the YouTube content pipeline,
  distilled from the
  [12-prompt playbook](../research/2026-07-15-youtube-12-prompt-playbook.md).
