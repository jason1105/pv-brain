# User Guide

## Purpose
This guide explains how to organize and evolve knowledge in pv-brain.

## Knowledge lifecycle
Brainstorm -> Research -> Knowledge -> Workflow -> Agents

## Directory guide
- brainstorm: raw ideas
- research: external findings
- knowledge: reusable knowledge
- workflow: business workflows
- adr: important architectural decisions

## Best practices
- One topic per document.
- Prefer updating knowledge over duplicating it.
- Record major decisions as ADRs.
