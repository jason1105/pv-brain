# Product Vision

## Vision

A system that behaves like an autonomous content company: give it an idea,
a topic, or a goal, and it produces finished, distribution-ready content
without a human doing the manual work at each step. Humans set direction and
taste; the system does the production.

## Product Positioning

pv-brain is not a video editor and not a single-purpose "AI tool." It is the
knowledge core of an **Autonomous Content Company** — an always-on cloud
service that plans, generates, assembles, and prepares content for
distribution. It competes on autonomy and repeatability, not on being one
more manual creation app.

## Core Philosophy

- **Workflow first.** The business workflow is the product. Agents, models,
  and prompts are implementation details that serve the workflow.
- **Cloud first.** The system runs as an always-on cloud runtime, not a
  desktop app tied to one machine.
- **Knowledge before code.** Durable thinking is captured as documentation
  before it is committed to implementation.
- **Humans supervise, the system executes.** People provide judgment and
  taste; the system carries out the repetitive production work.

## Long-term Goal

An autonomous creator that reliably turns intent into published content at
scale — a company that runs itself, where the human role shifts from
operator to director.
