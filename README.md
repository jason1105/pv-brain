# pv-brain

**pv-brain** is the long-term knowledge repository for building an
**Autonomous Content Company** — a cloud-native system that turns an idea
into finished, distribution-ready content with minimal human intervention.

This repository is a *brain*, not an application. It holds the vision,
architecture, decisions, workflows, and research that guide the project as
it evolves. Code lives elsewhere; the durable thinking lives here.

## What lives here

| Directory | Purpose |
|-----------|---------|
| [`vision/`](vision/) | Why the project exists and where it is headed. |
| [`architecture/`](architecture/) | How the system is structured. |
| [`adr/`](adr/) | Architecture Decision Records — significant, dated decisions. |
| [`brainstorm/`](brainstorm/) | Dated, raw exploration notes. |
| [`knowledge/`](knowledge/) | Distilled, reusable domain knowledge. |
| [`workflow/`](workflow/) | Business workflow definitions. |
| [`agents/`](agents/) | Agent roles and responsibilities. |
| [`prompts/`](prompts/) | Reusable prompt building blocks. |
| [`research/`](research/) | External research and findings. |
| [`assets/`](assets/) | Diagrams and images referenced by documents. |

## Top-level documents

- [`ROADMAP.md`](ROADMAP.md) — the phased plan.
- [`CHANGELOG.md`](CHANGELOG.md) — notable changes to the knowledge base.

## Principles

- **Documentation only.** No implementation code lives in this repository.
- **Markdown everywhere.** Every document is Markdown.
- **Concise by default.** Every README stays short and to the point.
- **Every directory explains itself** with a `README.md`.
