# Brainstorm

Dated, raw exploration notes. These capture thinking as it happens —
discussions, ideas, and open questions — before they are distilled into
`knowledge/` or hardened into `architecture/` and `adr/`.

## Conventions

- Notes are grouped by year (e.g. [`2026/`](2026/)).
- Each file is named `YYYY-MM-DD-topic.md`.
- Notes are allowed to be exploratory and incomplete; they are a record of
  the conversation, not a final decision.
